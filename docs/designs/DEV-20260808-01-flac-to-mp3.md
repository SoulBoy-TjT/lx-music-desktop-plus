## 模块边界

- `src/main/modules/flacConverter/`：独立深 module；小 interface 提供能力查询、预览、执行和进度订阅，implementation 隐藏 FFmpeg 进程、参数、超时、输入变化检查、临时文件与不覆盖发布。
- `src/main/modules/audioFfmpeg/`：歌曲整理与转换 module 共用的内置 FFmpeg 路径和可用性 adapter，不包含任何转换业务状态。
- 类型化 IPC：提供歌手扫描、预览、执行、暂停/继续和进度事件；Renderer 不直接访问文件系统或启动进程。
- `src/renderer/views/FlacConverter/`：独立页面 module，负责下载目录歌手列表、可选输出父目录、逐行操作、行内进度和异常结果展示。
- `src/renderer/views/SongOrganizer/`：不导入转换类型或 IPC，不展示转换入口。

## 转换流程

1. Renderer 默认读取当前 `download.savePath`，也允许页面级选择其他来源根目录；请求 Main 扫描一级歌手文件夹，可选自定义输出父目录。页面级来源选择不写入全局下载设置，应用重启后恢复默认下载目录。
2. Main 排除重解析点以及无数量、带数量的自动 MP3 输出目录，递归统计每个歌手的普通 FLAC 与 MP3；同时在输出父目录中解析同一来源基础名的输出候选。零个候选返回无数量工作目录，一个合法候选直接复用，多个候选或重解析点候选返回可定位阻断，不猜测或合并。
3. 用户点击歌手行“转换”后，Renderer 内部请求预览并立即执行全部安全项目，不再显示预览确认弹窗。
4. Main 对 FLAC 使用 FFmpeg，对 MP3 使用同目录临时文件复制；两者均检查输入变化、禁止覆盖并原子发布。
5. 每个文件以以下等价参数串行编码：

   ```text
   ffmpeg -v error -nostdin -i <source> -map 0:a:0 -map 0:v? -map_metadata 0
          -c:a libmp3lame -b:a 320k -c:v copy -id3v2_version 3 -f mp3 <temp>
   ```

6. Main 逐级创建缺失的输出目录并拒绝既有重解析点；处理后复核输入身份、大小和修改时间，通过硬链接创建最终目标以保证不覆盖，再删除临时路径。
7. 暂停控制器在项目边界等待；暂停请求、已暂停、继续、当前项目和计数均通过进度事件广播。
8. 批量完成后 Main 重新统计来源 FLAC+MP3 与当前输出目录的普通 MP3，以实际 `outputSongCount` 计算同一父目录下的“`<来源基础名> MP3（N首）`”终态路径。当前名称不正确时执行不覆盖的安全改名；目标已存在、路径链含重解析点或改名失败时保留现有目录并返回操作异常。
9. 部分文件失败、跳过或来源/输出数量不一致不阻止终态实际数量命名；Renderer 使用 Main 返回的最终 `outputDirectory` 刷新歌手行，同时继续只在跳过、失败、数量不一致或操作错误时展示异常明细。来源歌手目录和用户选择的输出父目录不参与改名。

## 失败与清理

- FFmpeg 无法启动、超时、非法音频或封面不兼容均作为当前文件失败，继续下一项。
- 进程 stderr 限制在 16 KiB，避免异常输出无限占用内存。
- 临时文件在 `finally` 中清理；最终目标发布失败时不修改既有目标。
- 同一来源基础名存在多个输出候选、终态计数目录由其他路径占用或任一路径是重解析点时，在对应磁盘步骤前阻断；不覆盖、合并、删除或自动挑选目录。
- 转换期间 `FlacConverterService.isBusy()` 为真；应用退出编排同时查询歌曲整理和转换 module，任一繁忙都阻止退出。
- 转换 module 不触发或持有歌曲整理扫描；输出位于歌曲整理目录时，由歌曲整理下一次正常扫描识别。

## 2026-09-11 异常操作

- Renderer 异常由字符串改为包含 `message` 和可选 `sourcePath` 的结构；逐文件异常调用现有 `openDirInExplorer(sourcePath)` IPC，在资源管理器中定位源文件。数量及操作级异常不伪造歌曲路径。
- 异常区域单独调用重试处理函数，通过现有 apply IPC 的可选 `retrySourcePaths` 指定异常源歌曲；Main 在同一运行互斥内解析实际带数量输出目录，验证全部范围后仅删除对应输出目录直属普通 MP3，重新 preview 并只转换选定父目录直属歌曲。使用来源歌手根目录保持输出相对路径、进度和终态计数，不另建专辑 MP3 根目录。
- Renderer 排除“目标 MP3 已存在”这一正常跳过原因；无具体路径时禁用重试。重试失败保留原异常范围，成功后使用本轮异常替换。路径校验和取消检查在每次清理前重复执行；不递归删除目录。
