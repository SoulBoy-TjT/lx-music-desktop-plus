# 正式安装包构建隔离与校验

- 问题：已安装 app.asar 的 main.js 含 eval-source-map，并加载 localhost:9080；正式安装后无开发服务器导致空白错误页及开发工具窗口。
- 开发与正式构建必须使用不同输出目录；开发启动器使用开发目录入口。正式打包前阻断开发模式产物、缺失入口及 HTML 引用资源缺失，包内再校验同一规则。
- 保留用户数据库、配置与音乐文件；重新生成安装包，用隔离用户目录启动打包后的完整程序，确认本地 index.html 加载且界面根节点可见。
- 不修改安装路径、不依赖用户运行开发服务器。无法从当前进程列表确定先前产物被改写的具体进程，但开发与正式共用 dist 是已确认风险。
