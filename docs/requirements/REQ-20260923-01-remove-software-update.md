# 移除软件更新检查

- 移除启动及同意协议后的软件更新检查、后台下载和重启安装、联网版本信息获取及更新/更新日志弹窗。
- 设置页保留本机版本与构建信息，标题改为“版本信息”，不展示在线版本状态和自动更新开关。
- 移除专用 IPC、状态、默认配置和 electron-updater 运行依赖；旧用户配置中的遗留键无需删除，程序不再读取。
- 歌单自动更新、音乐源脚本更新提醒及手动下载安装能力不变；发布脚本不属于运行时更新检查。
- 验收：运行代码和构建产物不包含软件更新请求入口；Main/Renderer 类型检查、定向 ESLint、构建通过。

## 验证

Main/Renderer 类型检查、定向 ESLint 和 production build 通过；最终主进程及界面产物断言未包含更新请求入口。实际桌面启动和安装尚未验证，安装包仍为上一轮版本。
