## 决策

用户于 2026-08-08 要求参照 Easy Music 修改目录行为，因此接受以下安排：

1. 输入由多选单个 FLAC 改为选择一个来源目录，并递归发现其中的普通 FLAC 文件；不跟随目录联接、符号链接或其他重解析点。
2. 未选择输出父目录时，在来源目录同级创建自动输出子目录；名称去掉来源目录末尾的 `（N首）` 或 `(N首)` 后追加 ` MP3`。
3. 用户可以选择自定义输出父目录，实际 MP3 仍写入该父目录下由程序计算的“来源名 MP3”子目录；用户选择的父目录本身不改名。
4. 输出目录位于来源目录内部时，扫描必须排除整个自动输出子树，避免把历史输出重新作为输入。
5. 递归扫描保留来源目录中的相对层级，`.flac` 扩展名替换为 `.mp3`。
6. 继续只转换 FLAC，不复制来源目录中的既有 MP3，也不追加转换后曲目数后缀；固定 320 kbps、保留源文件、禁止覆盖及原子发布规则不变。

## 理由

目录级输入更适合批量转换完整歌手或专辑树。默认同级输出无需每次选择路径，自定义输出父目录又能覆盖跨磁盘导出场景。只复用 Easy Music 的目录解析与相对路径模型，可以满足当前要求而不引入复制 MP3、目录计数重命名等额外业务语义。
