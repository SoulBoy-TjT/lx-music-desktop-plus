## 修订范围

本决策修订 `BIZ-20260807-03` 第 1、4、5、7、8 节及视觉方向中的固定扫描状态、固定详情日志和结果反馈方式，并修订 `BIZ-20260808-01` 第 1、4 节及代价与风险中的双列审计带。启动后台预扫描、Main 单任务运行态、无跨扫描缓存、路由保活、行级安全操作和五列表格规则继续有效。

后续 `BIZ-20260810-03` 只收敛本决策第 2 节的普通“查看详情”内容：不再展示歌手与专辑正常目标，只展示异常与阻塞；清理确认、操作结果和弹窗时序条款不变。

后续 `BIZ-20260810-04` 明确固定扫描状态继续移除，但用户主动发起的重命名必须显示独立数值进度；该进度不等同于扫描状态。

## 决策

### 1. 页面不再固定展示扫描状态

- “扫描状态”卡片、扫描摘要、进度条、当前文件和页面内“取消扫描”入口全部移除，后台扫描不再占用表格上方的固定空间。
- Main 仍保存并发布可查询、可订阅的扫描运行态；Renderer 继续据此接管快照、禁用扫描期间的目录切换和磁盘操作，并拒绝旧任务覆盖新结果。
- FFmpeg 或平台能力不可用时仍使用原有整页不可用提示；未完成操作恢复警告仍独立展示。本次只移除正常工作区内的扫描状态区域，不放宽任何能力或恢复边界。

### 2. 最近详情改为按需弹窗

- 页面不再固定渲染“最近详情”容器，也不为其保留空白占位。
- 点击歌手行“查看详情”后打开详情弹窗，展示歌手与专辑目标、异常文件、状态和阻塞原因；长内容在弹窗内部滚动，文件路径允许选择复制。
- 清理预览与二次确认合并到同一个详情弹窗；用户可以核对具体目标后确认或取消。
- 清理、重命名和恢复操作的成功、跳过、失败及回滚结果在操作结束后使用同一详情弹窗反馈；后台自动重扫不得改写已经打开的内容。
- 页面失活时关闭当前弹窗；磁盘操作在其他页面完成时只暂存结果，返回歌曲整理页面后再打开，不得覆盖其他页面。
- 同一时刻只显示一个歌曲整理详情弹窗，新详情替换上一次详情，不在页面中保留第二个日志视图。

### 3. 工作区收敛为目录轨道与结果表格

- 主工作区固定结构收敛为“标题与说明、扫描目录轨道、五列歌手表格”；恢复警告仍位于工作区上方。
- 移除双列审计带及其窄屏堆叠规则，表格直接承接目录轨道后的剩余空间，继续使用吸顶表头和内部滚动。
- 状态标签只表达各歌手的可执行计划与阻塞原因，不承担全局扫描进度展示。

## 代价与风险

- 页面不再提供手动取消后台扫描的入口；目录变化、新扫描替换和应用退出仍由 Main 现有取消机制回收任务及 FFmpeg 子进程。
- 扫描期间缺少持续进度反馈，但目录按钮与磁盘操作仍会保持禁用，完整快照到达后一次性刷新表格。
- 详情移入弹窗后必须保证长路径、长列表可滚动和选择复制，且清理确认不能丢失逐项目标信息。

## 确认记录

移除固定扫描状态、将最近详情改为弹窗且不再固定展示，由用户于 2026-08-08 明确提出，本决策直接记录为 `accepted`。
