# FLAC 转 MP3 输出歌手目录追加实际歌曲数量

## 关联文档

- 来源需求：[REQ-20260808-01 FLAC 批量转换为 MP3](../requirements/REQ-20260808-01-flac-to-mp3.md)
- 被修订决策：[BIZ-20260808-04 FLAC 转 MP3 采用来源目录与可选输出父目录](BIZ-20260808-04-flac-converter-directory-output.md)
- 被修订决策：[BIZ-20260809-01 FLAC 转 MP3 使用歌手列表、行内进度与异常结果](BIZ-20260809-01-flac-converter-artist-workspace.md)
- 技术方案：[DEV-20260808-01 FLAC 批量转换为 MP3 技术方案](../designs/DEV-20260808-01-flac-to-mp3.md)

## 决策问题

既有规则将输出歌手目录固定命名为“来源名 MP3”，并明确不追加歌曲数量。用户于 2026-08-10 要求转换完成后在该歌手文件夹名称后追加实际歌曲数量，例如“刘雨昕 MP3（199首）”。

## 决策

1. 自动输出目录的基础名称继续先去掉来源歌手目录末尾的 `（N首）` 或 `(N首)`，再追加 ` MP3`；转换终态名称统一为“`<来源基础名> MP3（N首）`”。来源歌手目录本身永不改名。
2. `N` 是转换终态重新递归统计所得的输出目录普通 MP3 文件实际数量，不使用来源预估数、本次成功数或进度计数代替。
3. 单项失败、跳过或来源/输出数量不一致时，仍按终态实际 `N` 更新输出目录名称，同时继续返回原有异常明细；数量后缀只陈述现有 MP3 数量，不表示转换完整成功。
4. 每次扫描、预览和执行都在当前输出父目录中按同一来源基础名识别无数量目录和带数量目录。只有一个合法候选时复用该目录；不存在候选时才使用无数量基础目录作为新任务输出目录。
5. 同一来源基础名存在多个输出候选、候选或路径链包含重解析点、终态目标目录已经由另一个路径占用时，操作必须阻断并报告具体路径，不得猜测、覆盖、合并或删除目录。
6. 转换终态统计完成后，在同一输出父目录内将当前唯一候选安全改名为目标数量名称；当前名称已经正确时不执行磁盘改名。改名失败作为操作异常返回，已生成的 MP3 和来源文件保持不变。
7. 默认来源同级和用户指定输出父目录使用完全相同的候选识别、计数命名和冲突保护规则；用户选择的输出父目录本身不改名。
8. 无数量和带数量的自动 MP3 输出目录都必须从来源歌手列表与来源音频扫描中排除，避免重复转换历史输出。

## 对既有决策的修订

- 修订 `BIZ-20260808-04` 第 2、3、6 条：保留来源同级、可选输出父目录、相对层级与安全发布规则；“来源名 MP3”为工作基础名，最终名称追加实际歌曲数量，不再适用“不追加转换后曲目数后缀”。
- 修订 `BIZ-20260809-01` 第 1、7 条：无数量和带数量输出目录都不作为歌手来源；最终输出目录使用实际歌曲数量后缀。

## 确认项

- [x] 转换终态目录使用“`<来源基础名> MP3（N首）`”，`N` 为输出目录实际普通 MP3 数量。
- [x] 部分失败仍按实际数量命名，并继续保留失败、跳过和数量不一致异常。
- [x] 重复运行只复用唯一合法候选；多个候选、目标冲突或重解析点均阻断且不覆盖、合并或删除。
- [x] 来源歌手目录和用户选择的输出父目录均不改名。
