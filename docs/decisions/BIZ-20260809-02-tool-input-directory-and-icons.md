## 决策

用户于 2026-08-09 根据实际页面反馈确认：

1. FLAC 转 MP3 页面仍默认使用当前下载目录，但允许在页面内选择任意受支持的来源根目录；切换只影响转换页面，不修改全局下载设置，并可一键恢复当前下载目录。
2. 专辑抓取移除“当前音源能否用于下载”的说明条。输入改为歌手名称，例如“蔡徐坤”；酷狗搜索只接受名称完全匹配的候选，多个完全匹配项按 Provider 顺序取首项，并继续使用既有歌手名称、ID、头像确认弹窗防止误抓。
3. 数字歌手 ID 与酷狗官方歌手链接继续作为兼容输入，但界面只引导歌手名称，不再要求用户查找 ID 或链接。
4. “专辑抓取”“歌曲整理”“FLAC 转 MP3”使用三个语义不同的导航图标；图标沿用侧边栏的 `currentColor`、尺寸、主题选中态和单色轮廓风格，不另设颜色或装饰。

## 被修订内容

- 本决策局部修订 `BIZ-20260805-01` 的“输入使用精确歌手引用”：默认交互改为歌手名称精确搜索，但来源边界、专辑详情完整性和人工确认继续有效。
- 本决策局部修订 `BIZ-20260806-02` 的导航视觉安排：三个独立页面必须使用不同图标。
- 本决策局部修订 `BIZ-20260809-01` 的默认下载目录行为：默认值保留，同时增加页面级来源目录选择。

## 理由

歌手名称是用户最容易识别的输入，完全匹配加确认步骤可以在降低操作门槛的同时保留身份校验。页面级目录选择不会意外改变下载器保存位置。三个工具图标分别表达在线专辑、本地整理和格式转换，能避免当前三个相同音乐文件夹图标造成的识别困难。
